Initial release

* Supports Autosomal Dominant and Autosomal Recessive modes of inheritance with the exception of consanguineous Autosomal Recessive cases which are not currently supported.  X-Linked cases are not currently supported and are scheduled for a subsequent release.

V2.0
* Add features to support consanguineous Autosomal recessive and X-linked
* Debug the html plots

V2.1
